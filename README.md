# Table Studio

Make Markdown tables feel like Notion tables: drag column borders to resize, highlight headers, pick a table style, give rows more room, freeze the header row or first column, color rows and columns, align text, transpose, and copy tables as CSV, TSV, HTML or LaTeX. Your notes stay plain Markdown.

Available in English, 简体中文, 繁體中文, 日本語, 한국어, Deutsch, Français, Español, Português (Brasil) and Русский.

让 Markdown 表格拥有 Notion 表格般的体验：拖动列边框调整大小、突出显示表头、选择表格样式、为行留出更多空间、固定表头行或第一列、为行和列设置颜色、对齐文本、转置，以及将表格导出为 CSV、TSV、HTML 或 LaTeX 格式。笔记仍保持纯 Markdown 格式。

## Features

### Column width
- **Drag to resize**: hover the right border of a column until a blue line appears, then drag. Only that column changes, like in Notion. Press Esc to cancel.
- **Fit to content**: double-click a border. Shift + double-click fits every column.
- **Border menu**: right-click a border to fit columns, toggle text wrapping or set a background color for that column, distribute widths evenly, or reset.

### Table menu (⋯)
Hover a table and click the **⋯** button at its top-left corner:
- **Highlight header row / first column**
- **Style**: Default, Minimal (no vertical lines), Three-line (academic) or Striped rows
- **Spacing**: Obsidian default, Comfortable or Spacious
- **Freeze header row / first column**: long or wide tables scroll inside a box while the header row or first column stays in place
- **Align text**: the column or row you last clicked, selected rows or columns, or the whole table
- **Background color**: eight theme-aware colors for rows or columns
- **Wrap text**: per column; columns that don't wrap are cut off with an ellipsis, and the full text floats over the table while you edit
- **Transpose**: swap rows and columns
- **Copy as**: CSV, TSV (paste into Excel), HTML (paste into Word) or LaTeX (booktabs, formulas kept)

### Selection toolbar (Live Preview)
Select whole columns or rows with Obsidian's own table selection (click a row or column drag handle, or drag across cells). A small toolbar appears to align or color the selection.

### Spacing only where you want it
Spacing and vertical alignment apply only to tables you've adjusted with this plugin (resized, or changed from the ⋯ menu). Other tables keep Obsidian's look.

## What is stored where

| Change | Stored in |
| --- | --- |
| Column alignment, transpose | Your note (standard Markdown, for example `:---:`) |
| Everything else: widths, styles, highlighting, spacing, freezing, colors, wrapping, row alignment | The plugin's `data.json` (synced with your vault, notes untouched) |

Markdown has no syntax for row alignment or colors, so those are only visible while this plugin is enabled.

Settings follow a table when you edit cells, add or delete rows, rename headers, add, remove or reorder columns, or rename or move the note.

## Commands

- Reset adjustments of all tables in the current note
- Clear all adjustments of the table at the cursor
- Fit all columns of the table at the cursor to content
- Transpose the table at the cursor

## Limitations

- Tables generated by code blocks (for example Dataview) aren't supported.
- Transposing resets column widths, alignment, colors and wrapping.
- Per-column wrapping and colors support up to 32 columns.
- Translations other than English and Chinese were written without a native-speaker review. Corrections are welcome.

## Installation

**From Community plugins:** Settings → Community plugins → Browse → search "Table Studio" → Install → Enable.

**Manually:** download `main.js`, `manifest.json` and `styles.css` from the latest release into `<vault>/.obsidian/plugins/table-studio/`, then enable the plugin in Settings → Community plugins.

## Development

`main.js` and `styles.css` are generated. Edit the files in `src/` and rebuild:

```
python3 build.py
```

- `src/core.js`: plugin code
- `src/locales.js`: UI text for all languages (corrections welcome)
- `src/base.css`: styles; per-column rules are generated by `build.py`

No npm dependencies are needed.

## Privacy

The plugin makes no network requests and collects no data.

## 中文说明

让 Obsidian 的 Markdown 表格用起来像 Notion：拖动调整列宽、标题高亮、表格样式、更从容的行距、冻结标题行 / 首列、行列背景色、文字对齐、行列互换，以及复制为 CSV / TSV / HTML / LaTeX。笔记保持纯 Markdown。界面支持 10 种语言，默认跟随 Obsidian。

**列宽**：鼠标移到列的右边框，出现蓝色竖线后拖动；双击边框适应内容；右键边框可以设置这一列的换行和背景色。

**表格菜单（⋯）**：鼠标悬停在表格上，点左上角的 ⋯ 按钮：
- 标题行 / 标题列高亮
- 样式：默认 / 极简（无竖线）/ 三线表 / 斑马纹
- 行距：Obsidian 默认 / 舒适 / 宽松
- 冻结标题行 / 首列：长表格或宽表格在框内滚动，标题行和首列保持不动
- 文字对齐：最后点击的那一列、那一行、选中的行 / 列，或整个表格
- 背景色：8 种跟随主题的颜色，用于行或列
- 自动换行：按列设置；不换行的列显示省略号，编辑时完整内容浮在表格上方
- 行列互换（转置）
- 复制为：CSV、TSV（可直接粘贴到 Excel）、HTML（可粘贴到 Word）、LaTeX（booktabs 三线表，保留公式）

**选中工具条（实时预览）**：选中整列或整行后，旁边出现对齐和背景色按钮。

**保存位置**：列对齐和转置直接写进笔记（标准 Markdown）；其余设置保存在插件的 `data.json` 里，不改笔记。

插件不联网，不收集任何数据。
